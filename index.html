Windows Desktop Tool · v0.6.0

Book Capture AI

画面に通常表示できる電子書籍を、自動ページ送りでキャプチャし、見開き分割・ヘッダー/フッター除去・PDF生成・日本語OCRまでローカルPCで処理します。

WindowsOCR内蔵見開き分割ローカル処理
使い方を見る Windows最新版を取得 GitHub

最短の流れ

本を開く → 範囲を選ぶ → キャプチャ開始 → PDF/OCR完成

見開き対応

1回の見開きスクリーンショットを左右2ページへ分割。日本語書籍は右→左、洋書は左→右を選べます。

固まらない後処理

キャプチャ後の分割・PDF・OCRはバックグラウンドで実行。画面には処理段階と進捗を表示します。

OCR内蔵

Tesseract OCRと日本語/英語モデルをWindows配布版へ同梱。別途OCRソフトを入れずに検索可能PDFとTXTを作れます。

利用範囲について： DRM解除、暗号化解除、キャプチャ防止機能の回避は行いません。通常表示できるコンテンツを、著作権・利用規約等で認められる範囲で使用してください。

Book Capture AI はWindowsデスクトップアプリです。このGitHub Pagesは公開案内・マニュアル用ページです。
